# Datos de entrada

El fichero necesario es `rendimiento_estudiantes.csv`, separado por punto y coma. No se incluye ni se descarga automáticamente: utiliza una copia cuya procedencia y autorización de uso hayas verificado. La variable de clasificación se denomina `objetivo`; el resto del esquema se puede consultar en los scripts.

No sustituyas los datos por información personal de estudiantes. Este repositorio contiene el código del ejercicio, no un sistema validado para tomar decisiones educativas.
